# 💰 Мой Финансовый Путь

Приложение для управления кредитами и формирования привычки платить себе.

## Возможности
- 💳 Учёт до 10 кредитов с автоматическим расчётом
- 🌱 5 миссий "Плати себе" (4, 8, 12, 16, 20 недель)
- ⚡ Досрочное погашение кредитов
- 🔔 Уведомления в 10:00, 13:00, 18:00
- 🏆 Архив достижений

## Сборка
APK собирается автоматически через GitHub Actions при push в main.
